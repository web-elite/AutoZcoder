# AutoZCoder 3.0.1

## Bugfix

- The desktop launcher now writes the full process log to
  `%LOCALAPPDATA%\ZcodeGateway\zcode-gateway.log` from the moment it starts.
  Previously the file only received records once the gateway server booted
  (uvicorn's own logging setup); when startup failed earlier — a bad import,
  an unreadable config, a port bind failure — the log stayed empty and the
  "Zcode Gateway could not start" dialog gave you nowhere to look.
